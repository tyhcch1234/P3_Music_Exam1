# 小三音樂溫習室 · P3 Music Revision

Interactive revision site for the Primary 3 (1st Term) Music Booklet.

- 五線譜 Stave — lines, spaces, ledger lines, three clefs
- Unit 1 Music and Atmosphere — 2/4, conducting, orchestra families, pp / rit.
- Unit 2 World Music — sol-fa hand signs, binary/ternary form, rhythmic ostinato
- Unit 3 Play the Recorder — tonguing, fingerings, notes B A G
- Unit 4 Play Music Together for Christmas — untuned percussion

Each lesson has an interactive teaching section followed by a quiz.
All sounds are synthesised in the browser with the Web Audio API; no audio files are downloaded.
